🎬 MovieCity

MovieCity é uma landing page com temática cinematográfica, criada para apresentar o universo dos filmes por meio de uma interface moderna, visualmente atraente e intuitiva.

🖥️ Sobre o projeto

O projeto tem como proposta explorar o desenvolvimento de interfaces web, combinando design, organização visual e experiência do usuário em uma página inspirada em plataformas de cinema e streaming.

✨ Funcionalidades
Interface com identidade visual inspirada no cinema.
Layout organizado e intuitivo.
Apresentação visual de conteúdo cinematográfico.
Estrutura adaptável para diferentes dispositivos.
🛠️ Tecnologias
HTML5
CSS3
JavaScript
🚀 Como executar
git clone URL_DO_REPOSITORIO
cd MovieCity


Abra o arquivo index.html no navegador para visualizar a página.
