🎬 MovieCity — Landing Page
📌 Sobre o projeto
A MovieCity é uma landing page inspirada no universo do cinema, desenvolvida para apresentar filmes de forma moderna e atrativa. O projeto busca proporcionar uma experiência visual agradável, com um layout intuitivo e foco na divulgação de conteúdos cinematográficos.

🚀 Funcionalidades
🎥 Apresentação visual com temática cinematográfica.
🍿 Layout moderno e atrativo.
📱 Design responsivo para diferentes tamanhos de tela.
🎨 Interface organizada e intuitiva.
🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript

Este projeto foi desenvolvido com o objetivo de praticar e demonstrar habilidades em desenvolvimento web, criação de interfaces e construção de landing pages.
